# Parsetting site

Информационный сайт [parsetting.ru](https://parsetting.ru): возможности программы, лицензии и услуги внедрения. Статические HTML, CSS и JavaScript.

## Требования

Node.js 24 или новее. Внешних npm-зависимостей нет.

## Запуск

Откройте корень проекта в IDE и выполните:

```sh
npm ci
npm run dev
```

Локальный адрес: http://127.0.0.1:4320.

```sh
npm test
npm run build
```

Сборка для публикации появится в `dist/`.

## Настройки

Домен, тарифы и контакты заданы в `site.config.json`. После изменения выполните сборку. `PORT` и `SITE_DIST` задаются переменными окружения для `serve.mjs`; примеры приведены в `.env.example`.

Кабинет и API лицензий находятся в отдельном проекте `parsetting-api`. Сайт готовит сообщение для Telegram; отправку выполняет пользователь.
